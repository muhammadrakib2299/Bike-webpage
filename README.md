# Bike Showroom Landing Page

A landing page template for a motorbike showroom, built with HTML, CSS and Bootstrap.

**Live demo:** https://muhammadrakib2299.github.io/Bike-webpage/

## Sections / Features

- A Bootstrap navbar with a collapsible mobile menu and a Login button
- A Honda CBR 300R hero whose **Purchase** button opens a Bootstrap modal showing the price
- "Featured Bikes 2021" (side images in grayscale) and "Latest News" cards
- "Happy Clients Says" testimonial cards with Font Awesome star ratings
- An FAQ accordion built with Bootstrap collapse
- A "Choose Bikes By Brands" logo grid and a "Free Accessories" product row

## Built with

HTML5 · CSS3 · Bootstrap 5.0.2 (CSS and JS bundle via CDN) · Font Awesome 5.15.3 · Google Fonts (Poppins)

## What I practised

- The Bootstrap grid (`col-lg-*`, `col-sm-*`) for responsive rows
- Bootstrap's JavaScript components: navbar collapse, modal and accordion
- Bootstrap spacing and colour utilities, plus small custom CSS (brand colours, a `grayscale` filter)

## Run locally

Open `index.html` in a browser.
